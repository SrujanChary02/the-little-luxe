# The Little LUXE

Website for The Little LUXE — everyday accessories & jewelry.

## Posting new jewelry
1. Add the photo to the `images/` folder.
2. Open `products.js`, copy a product block, and edit its details.
3. Commit and push — the site updates in about a minute.

**Photo names:** use lowercase with dashes (e.g. `pearl-hoops.jpg`) and type the name in
`products.js` exactly the same. The live site treats `Photo.JPG` and `photo.jpg` as different
files. If a photo can't be found, the site shows the placeholder drawing instead.

**Contact:** set your WhatsApp number at the top of `products.js`. Until it's set, order
buttons send customers to your Instagram DMs.
